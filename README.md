# OpenExchange

Version `0.1.0-draft`. License: CC BY 4.0 (see [LICENSE](LICENSE)).

The exchange-venue companion to [OpenBook](https://github.com/openbook-data-standards/openbook):
venue descriptors, exchange market state, runners/selections, back/lay order-book
depth and fee profiles — the surface betting and prediction exchanges expose that
OpenBook documents cannot carry.

Spec: [spec/openexchange.md](spec/openexchange.md). Schemas: [schema/](schema/).
